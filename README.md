# Data Analyst Job Market Analysis

## Project Overview

This project analyzes Data Analyst job postings to identify commonly
requested technical skills and examine how those skills relate to salary.

The analysis was completed using R and RStudio and includes data
visualization, descriptive statistics, correlation, regression, and
statistical testing.

## Analysis

This project examines:

- Common Data Analyst skills
- Average Data Analyst salary
- Salary distribution
- Python skills and salary
- Minimum and maximum salary relationships
- Work-from-home jobs and salary
